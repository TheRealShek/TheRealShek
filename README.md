I mostly write **Go**. **Rust** has been taking up more of my time lately. I like building things from the ground up: **version control, containers, and task queues**. That is usually how I learn what is really going on.<br>
I build **systems that stay calm under load**. *I'm trying to learn the trick myself.*

**Things I've built**<br>
▸ **[open-mpv](https://github.com/TheRealShek/open-mpv)** · *[Rust]* · Fast photo and video viewer for GNOME. Browse folders directly, without imports or a media library.<br>
▸ **[Fervion](https://github.com/TheRealShek/fervion)** · *[Rust + Go]* · Experimental offline-capable VCS with content-addressed storage, scoped encryption, and first-class support for AI agents.<br>
▸ **[aiContext](https://github.com/TheRealShek/aiContext)** · *[Go]* · One `AGENTS.md` as the source of truth across Codex, Claude Code, Cursor, Copilot, and Gemini CLI.<br>
▸ **[Persephone](https://github.com/TheRealShek/persephone)** · *[Go]* · From-scratch VCS experiment rethinking Git around concurrency, modern hardware, and content-addressed storage.<br>
▸ **[mini-docker](https://github.com/TheRealShek/mini-docker)** · *[Go]* · Container runtime using Linux namespaces, overlay filesystems, and `pivot_root`.

**Tools I built for myself**<br>
I use **Fedora** and build for it. These are some of the tools that make my setup feel like my own.<br>
▸ **[Monitor Settings](https://github.com/TheRealShek/gnome-monitor-settings)** · *[Rust + GJS]* · Native GNOME controls for external monitor brightness, contrast, volume, and color over DDC/CI.<br>
▸ **[fleet](https://github.com/TheRealShek/fleet)** · *[Config]* · Reusable AI-agent instructions, skills, and adapters shared across tools.<br>
▸ **[voice-ai](https://github.com/TheRealShek/voice-ai)** · *[Rust]* · Private voice dictation running Whisper locally on my GPU, pasting transcripts into the active app.
